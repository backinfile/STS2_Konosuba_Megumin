一切围绕
这一发爆裂。

开始前创造条件，预备时已经影响战场，释放时集中兑现。余波是结果，不再是角色需要长期经营的核心资源。

01 / 问题重新定义

三个阶段，三个不同的决定。

上一版让爆裂成为余波引擎的启动器，这是设计偏移。本版把所有专属准备、增益与结算安排绑定到同一次爆裂实例。这次释放或中止后，准备记录全部结束。

施放前：创造条件

此时尚未进入预备。正常攻防、滤牌、减益与保护决定能否承担这次承诺。主要选择：现在付出进入费用，还是先处理危险？

预备中：效果已存在

魔法阵与光效出现，也有真实规则效果。可以调整这次爆裂并应对敌人；主要选择：继续准备的收益，是否值得额外等待或支付？

释放：集中兑现

读取本次准备，失去预备收益，结算爆裂与已安排善后。主要选择：现在结束准备，接下来能否活下来？

阶段可以设计什么主要代价不能偷换成什么
施放前保护、找牌、处理小怪、设置有限前置能量、抽牌位置、错过当前击杀无成本在后台永久叠爆裂资源
预备中限时压制、投入转换、当前施放的术式组合等待敌方行动、继续支付、占据一个施放实例永远不释放的常驻能力
释放结算主伤害、目标范围、护盾／抽牌安排、固定余效预备效果终止、准备清空、脱力窗口先保留全部准备，再免费复制伤害
预备不是单纯的过场，也不应该比释放更值得长期维持。

演出负责让玩家看到“这一发已经在形成”；规则负责让玩家在“继续准备”和“现在结束”之间选择。本版特意不把更多光圈、亮度或粒子数量再做成新资源。

视觉特效与规则反馈分开设计

阶段画面表现提案玩家必须能读出的信息
施放前法杖与人物处于普通姿态，尚无展开的魔法阵。尚未投入进入费，没有任何预备被动。
预备法杖前展开魔法阵，场上出现可辨识但不遮挡敌人意图的光效。咏唱方案逐级亮环，投入方案显示能量汇入，术式方案只显示两个已装图案。当前爆裂伤害预览、正在生效的预备效果、距离强制释放还差几个敌方阶段。不能只凭亮度猜数值。
释放魔法阵收束再爆发，清晰显示失去预备效果；演出可加速或减少闪光，不把动画长度算成本。这一发的伤害与善后已确定，准备清空，脱力与一次余效已登记。

用户明确提出预备时已有特效；将其同时设计为规则收益，是本轮为了增加决策提出的方案。若偏好只有视觉特效，可以移除预备被动，再单独检验准备阶段是否仍有趣。

队友在这里承担什么

和真整理手牌、协助改动计划；达克妮丝保护预备与脱力；阿库娅承载有限恢复或保护转交；芸芸可以补刀、处理预备前的小怪。队友卡不要求存在真实队友单位，也不各有独立计数器。并非每套都要塞齐所有角色。

02 / 共同测试底座

把进入、维持和退出的边界写清。

以下是用于比较的暂定规则，不是已获用户确认的最终规则。尤其“2费预付、最多两个敌方阶段、少1能量脱力”都需要原型推翻或保留。

初始牌组
暂用3能量、5抽牌。4张1费6伤害基础攻击、4张1费5格挡基础防御、2张1费抽2弃1的通用整理，共10张实体牌。每套另给固有进入／释放操作，不占抽牌。
进入预备
支付2能量，创建唯一“本次爆裂”。处于脱力、已经预备、或本回合刚释放／中止时不可进入。费用预付，因此主动和到期释放均为0费操作，不算普通牌；触发专属“释放”事件。
期限
最多跨过2个敌方阶段。若第N回合进入，可在N或N+1主动释放；跨过两次敌方阶段后，在N+2玩家回合开始强制释放。到期发生在正常抽牌与能量刷新之前；释放不需要额外能量。定时咏唱先进行本次自然加级，再到期释放。
玩家行动
预备中可以正常出牌，且可以同回合进入和释放。具体成长与预备收益按选定体系；不同时采用三套规则。所有“每轮”从当前玩家回合开始计至下一玩家回合开始前。
主动中止
提供0费中止操作，返还0能量、造成0伤害、没有余效；清空本次准备并进入与释放相同的脱力和再进入锁。中止不触发“释放后”奖励。它是取消选择的兜底，不是反复进入刷收益的路线。
脱力与再启
释放后仍可用当前剩余资源行动；下一玩家回合少获得1能量（不低于0），不能进入预备。该回合结束解除；再下个玩家回合可重新进入。第N回合释放，最早N+2再次进入。中止同样处理。
固定余效
释放后场上留下本次爆裂的残留，在下个玩家回合开始对所有当前存活敌人造成3点伤害，然后移除。没有层数、延长、消耗换资源的牌；战斗结束不带到下一场。它服务于“爆裂留下影响”的要求，不承担主要获胜引擎。
复制边界
复制普通准备牌仍需合法条件与实际支付。进入／释放不是可复制手牌，任何额外释放请求必须检查实例锁；不从同一准备快照重复生成爆裂。单发修饰默认同名不叠加，不同平加可相加。
无预备时
若牌有普通伤害／格挡／抽牌，则正常结算该部分，准备相关部分跳过；只有准备效果的牌无合法实例时不能打出。支付其他手牌、选择替换等成本必须在执行前验证合法。

术式补充：同一种类不能重复占位。完整格挡须为原始伤害大于0的一次攻击实际造成0失血；被动装入护发生在该攻击结束后，不追溯保护刚刚结算的攻击。护式效果的每敌每轮额度、破式与导式额度均按轮记录，替换不能刷新。
所有同名能力默认不叠加。预备的每轮首攻／首技能额度属于玩家当前这一轮，重新装入、替换或移除效果不能刷新额度。初始进入不追溯触发本回合已经打出的牌。

完整体系 / CHANT / 阶段1—5

定时咏唱

这一发随时间变强；现在释放，还是多承受一次敌方行动？

体系判定：大体系候选；围绕当前爆裂的咏唱等级、预备状态和释放事件，而非释放后的伤害资源。

进入

进入预备时咏唱为1。可以同回合释放，但不经过等待就只有低等级伤害。

预备持续

在预备期间，每个敌人每轮第一次攻击对你造成的总伤害降低2（整次攻击总计减2，多段不逐段减2）。你的下一回合开始时咏唱+1，上限3。牌可以加速咏唱，但不会推迟强制释放期限。

释放

快照咏唱Q，基础伤害为18+8Q，对所有敌人结算一次。移除预备压制与咏唱，随后进入脱力并留下共同余效。3级只是达到最大威力，不自动提前释放；仍可在期限内选择时机。

阶段1—2：从规则到构筑闭环

闭环与动机
进入预备 → 以减伤承受等待或花牌加速 → 高等级奖励改善护送与找牌 → 主动／到期释放 → 处理脱力 → 重新进入。加速牌让高等级更早到来，保护牌让低投入自然等待可行。
来源
每个后续玩家回合开始自然+1（非主动来源）；CHANT-04、06、09主动加速；01、02、03提供低稀有预备入口收益。初次预备由衍生入口完成。
三端口
输出04、07、09与爆裂；防御01、05、10及预备压制；运转02、03、06、08。三张以上非稀有抽牌，且效果发生在施放之前。
连接接口
09将消耗手牌接到本次咏唱加速；10把施放承诺转为下一回合保护。若以后设计消耗副轴，09是其触发端、咏唱的来源端；目前只称连接接口。
复杂度
中低：Q上限3＋统一预备期限；不再引入余波层数。
结构参照
采用本地设计文档的时间阶段、资源来源、消耗连接与范围突破模式；只借鉴结构，不宣称原作有逐层咏唱或当前游戏已有同机制。
排除方向
独立经营余波、每个队友的独立资源、无限维持的常驻场地不计入本体系。纯治疗和普通防御可以保留在通用层，不为凑数标成核心。

三种构筑路线

路线本体系卡号拿牌与操作偏好实际代价
快速成咒04、06、07、09多拿付费加速，少等敌人行动；用普通攻击补当前回合。减少暴露时间，但同样等级花了更多手牌与能量。
自然长咏01、02、03、05、08防御和滤牌护送自然升级，不把能量都花在加速。更省启动牌，但至多承受两个敌方阶段，不能无限驻留。
蓄势单发07、10、12升级窗口内准备增幅与跨回合保护，追求一击结束关键目标。牺牲普适性与卡位，释放之后不保留咏唱引擎。

阶段5：六视角审查与本版修订

由同一助手按文档允许的方式依次审查。以下是本轮纸面设计推理，不是独立agent意见或实战结果。

视角发现的问题处理
设计者预备若只加数字，还是普通蓄力。加入有期限的真实减伤；释放同时失去减伤，改变攻防时机。
规则审稿者满级是否自动放、到期增层先后不清。满级可继续持有至期限；回合开始先自然加级，再执行到期释放。
原版对照者加伤牌不等于突破。07按罕见核心收益处理；稀有改进入费用和目标范围。
平衡审稿者在减伤中无限等牌。至多跨两个敌方阶段；无卡牌延长期限。
体验审计者每次都等满两轮是否固定答案？对照早清小怪与高压首领；加速高等级会与当回合防御争能量。
整合者保留时间核心，移走永久余波成长。12张奖励牌组成完整单体系初版；高低压下选择差异待原型。

阶段5：六视角审查与本版修订

由同一助手按文档允许的方式依次审查。以下是本轮纸面设计推理，不是独立agent意见或实战结果。

视角发现的问题处理
设计者如果只每回合自然变强，与定时咏唱无区别。自然来源也实际消耗剩余能量；手动操作和卡牌改变资源投入速度。
规则审稿者注能是否打牌、满上限是否吞费？不是打牌，不触发首技能；满上限操作禁用且不吞能量。
原版对照者普通来源与稀有大数字差在哪里？稀有改变整手转换和容量，普通只按具体费用增长。
平衡审稿者投能量再抽牌返能量可能永动。本体系不提供能量返还；11整手消耗并自消耗，抽牌不超过一次重编。
体验审计者是否永远注满6才释放？用首回合危险敌人与2能量生存需求对照，要求低投入止损也成立。
整合者投入必须跟着这次爆裂结束。不保留P、不用余波返P；12张奖励牌覆盖三端口，资源汇率待测。

术式装填

这一发要威力、退路还是后续手牌？两个位置放不下全部答案。

进入

07 / 最容易出错的部分

释放是一笔结算事务，不是再开一套系统。

  1. 验证实例。确认处于预备且当前实例未释放；设为结算中，禁止重入。若有临场改咏，先处理唯一一次替换选择。
  2. 快照准备。读取Q、P或两个术式，以及这次施放的平加、范围和善后安排。快照之后抽到或触发的牌不能改写这一发。
  3. 移除预备状态。先失去压制、首技能护盾或术式被动。爆裂不会吃到专给“普通攻击”的破式加成，也不会在结算时继续积累准备。
  4. 计算主伤害。基础公式→本次平加→范围倍率→正常伤害修正与目标格挡。不同目标各自结算；这里只做一次爆裂释放事件，不按敌人数重复触发奖励。
  5. 处理善后。护式等即时格挡和导式等抽牌按快照执行；跨回合保护登记到相应时点。若战斗已经结束，停止剩余战斗内效果。
  6. 登记余效与脱力。只生成一次下回合3点场地伤害；进入脱力安排与再启动锁。准备数值／术式／本次修饰清空，不继承到下一发。

若游戏引擎的战斗结束、阶段切换或自动效果顺序与这份草案不同，需要适配并重测；本页没有声称已验证游戏API。单体爆破目标死亡时在释放前重新选合法敌人。

08 / 当前推荐

先验证定时咏唱，再用术式装填挑战它。

方案爆裂前预备的价值释放的变化最危险的退化
定时咏唱安排防守与加速减伤＋随时间增长失去压制，按等级兑现永远等满级，时机没有变化
投入蓄爆腾出能量与燃料首技能护盾＋真实投入清空本次投入，集中伤害永远注满载，变成复杂X费攻击
术式装填找组合与换式工具两式被动即时生效只兑现选中的两种收益永远固定带导，选择名存实亡

首选：定时咏唱。它最直接体现“爆裂正在形成”。

预备减伤让开始形成的爆裂立即改变战场；自然加级和主动加速提供两种准备路径；释放既获得伤害，也失去当前压制。这个反差最贴近你提出的三个阶段。

术式装填适合进一步强调“这一发怎么打”，比单纯等大数字更有构筑差别，但界面和规则负担更大。投入蓄爆作为资源决策对照，能检验是否真的需要自动计时，还是能量与手牌的竞争本身已经足够。

这三种是替代核心。可以在定时咏唱中借用一两张“调整范围／安排善后”的术式手法，但不因此再加入完整两槽系统，更不恢复旧版余波主轴。
