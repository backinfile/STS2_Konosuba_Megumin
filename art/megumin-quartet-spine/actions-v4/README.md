# 惠惠 · Spine 动作修订 v4

[交互预览](preview.html) · [九个关键帧](keyframes.html) · [54 帧过程检查](review-frames.html) · [Spine 导入包](megumin-actions-v4-import.zip)

2026-10-09。针对 v3 逐帧审查发现的问题重做动作。保留已认可的待机造型、呼吸和锚点；加入动作分件、局部表情、手掌支撑、松杖与重新握杖。旧版本保存在相邻目录，方便比较。

这是 Spine 4.2.11 JSON 数据，24 根骨骼、25 个插槽、18 段动作与一个静态检查片段。官方 Spine WebGL/Core 4.2.95 可以解析和播放。离线 `preview.html` 已内嵌运行库、图集和数据。

## 对应修正

| v3 的问题 | v4 的处理 |
|---|---|
| 杖头经过头部时被遮住、像从帽子里冒出 | 动作期间把法杖和握手置于头部前；抬杖经过单独的预备点，避开肘部求解死点 |
| 双手握点挤在腰部 | 主握点提高，双手沿杖相距约 60 个世界像素；吟唱与释放保持握点 |
| 施放手型不对、头脸几乎不变 | 新增张掌、专注吟唱、喊出与受击咬牙；只取眼睛、眉毛和嘴部的小区域 |
| 释放只转杖，头部抵消身体倾斜 | 增加身体前倾、收蓄、推出和回收；帽子与头发独立跟随 |
| 受击像疲劳闭眼 | 专用受击表情、快速冲量和稍后的帽发回弹；吟唱受击后恢复吟唱 |
| 肘膝折成尖角，动作中袖口重复 | 新的上下臂、分段腿和鞋底视图；站姿/动作分件使用不透明切换，避免交叉淡化重影 |
| 肩颈和披风出现缺口 | 补充独立衣服底层与上半披风，原图可见主体仍位于前层 |
| 脱力后还一直紧握法杖 | 右手切换松开的手型并解除杖上锚定；法杖独立落地，起身后再握回 |
| 披风被压成直切块 | 使用补画的平铺披风；上半披风的隐藏下缘折到地面，与平铺绘图衔接 |
| 起身没有手掌支撑，脚底滑移 | 左掌约 0.46–0.86 秒保持同一接地点；收腿、抬手、重新握杖、站起，最后分脚回到原站位 |
| 死亡和脱力几乎同姿 | 独立的低位蜷腿侧倒，手臂松开；死亡无呼吸并保持最后一帧 |

源图延续 v3 的细密纹理清理；新补画要求干净平涂。图集为带透明边距的 2 的幂尺寸，使用三线性 mipmap 缩小过滤，减少 320 px 下纹理和细线闪动。实际游戏仍需使用相同的纹理过滤设置。

完整顺序为吟唱进入 → 吟唱循环 → 爆裂释放 → 爆裂保持 → 卸力 → 倒下 → 脱力循环 → 起身。`relaxed_fall` 的起点是卸力末帧，单独选择时会直接显示该起点。不要把吟唱中的短动作统一排队回 idle，也不要为每个敌人或每段伤害重复播放身体释放。预览的三次伤害脉冲仅供演示，不执行游戏伤害。

## 验证与边界

[运行时检查](export/validation.json) 覆盖 2,962 个时刻、四肢 IK、可见网格接地、四个循环、14 处片段衔接、双手握点、支撑手接触、单次释放事件及死亡定格。54 帧页面用于查看中间过程；运行时数值通过不等于美术验收。

当前仍是侧向二维分件动画；大幅动作含手型、腿部、鞋底和披风的替换绘图，并非完整的多角度逐帧动画。尚未接入 STS2，未在原生 Spine 编辑器实际导入。交付 JSON、同内容的 `.spine-json`、图集和源图片；没有伪造原生 `.spine` 工程或 `.skel` 二进制文件。

Spine 4.2 编辑器可通过 Import Data 读取 `export/megumin.json`，图片路径为 `../images/`。运行时使用 `export/` 中 JSON、atlas 与 11 张 PNG 图集页。保留 4.2 版本匹配与 mipmap 过滤设置。

## 复现与美术来源

主图来自此前右手持杖的惠惠图，使用 v3 已清理的 `clean-reference.png`。新增 `arms-hands.png`、`legs-boots.png`、`costume-plates.png` 和三张局部表情参考由内置 imagegen 生成，提示词存于 `source/*-prompt.txt`。表情图片只取眼眉和嘴部；没有替换整张头脸。旧版补画来源和技术参考见 [上级说明](../README.md) 与 [v3 说明](../actions-v3/README.md)。

Python 只进行 UV 几何切分、骨骼绑定、时间线生成和图集装箱，不重绘源图像素。所有绘图源图哈希记录在 `export/manifest.json`。接地和握点处理均已写入标准 Spine 数据，运行时无需自定义 Python 或 JS 修正。

从上级目录运行：

```powershell
npm run build:actions:v4
npm run test:actions:v4
```

构建依次执行 `build_actions_v4.py`（载入 `actions_v4_overrides.py`）、`bake_floor_v4.mjs`、`validate_actions_v4.mjs`、`package_actions_v4.py`、`build_review_v4.py`。沿用上级目录已固定的运行库与 Python 几何依赖。
