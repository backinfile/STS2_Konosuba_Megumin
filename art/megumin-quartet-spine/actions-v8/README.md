# 惠惠动作 v8：体积和连续性修正

本版已接入项目内的 Slay the Spire 2 测试角色。v7 保留为问题复现基线。

## 变更

- 用头部实际不透明像素面积校准 13 张姿势图的比例。以前独立绘图的尺寸差异会在换附件时直接跳变。
- 头部改为固定形状的刚性部件，以可见像素重心定位；颈部仍单独控制躯干连接，不让身体控制网格拉伸脸和帽子。
- 握杖手保留每个姿势对应的角度绘图，校准可见面积和握点偏移，并采用刚性绑定。法杖仍为单根刚体。
- 腿部保留各姿势的绘图和局部绑定，避免跨透视复用造成裙摆和鞋子残片。
- 删除转身时远侧手臂在插值中点突然跨越大段距离的分支，改为连续运动并在躯干后遮挡。

## 查看与验证

- `index.html`：HTTP 预览，贴图独立加载。
- `preview.html`：完整离线预览。
- `verification/continuity.json`：可见像素加权的附件切换检查。
- `export/validation.json`：3511 个运行时采样，19 个动作、5 个循环、17 个动作衔接，以及握点、杖长、事件和网格检查。
- `verification/native-lab.json`：原生游戏中的 19 个动作和战斗验证。
- `verification/native/`：游戏渲染的换图前一帧、换图帧、后一帧对照。
- [游戏内原速录像](verification/recordings/index.html)：19 个单项动作、完整动作链和正常战斗；实时原速、无声，附实际采集帧率及逐段时间线。
- `verification/mcp-smoke.json`：真实 MCP stdio 握手和读取游戏状态。
- `verification/moire.json`：43 张源图与参考图的原尺寸 Mi-Ripple 检查；当前使用的 31 张素材未检出目标伪影，原像素与 alpha 保留。诊断热点、局部裁切和处理记录在 `verification/moire/`。

构建：在上一级目录执行 `npm run build:actions:v8`。复测：`npm run test:actions:v8`。
构建检查图片哈希与去摩尔纹复核记录；替换图片后必须重新执行并复核，旧记录不能用于新图。

可见像素检测与 v7 使用同一算法、同一阈值。头部面积切换阈值 6%，重心瞬移阈值 4 个 Spine 单位；握杖手对应阈值为 1% 和 1 单位。腿部与躯干结合遮挡和透视做画面复核。绘图视角改变仍可能带来线条或轮廓切换，这些数值不等于美术最终验收。原生 Spine 编辑器导入尚未实测。

卡牌、遗物、药水、奖励池及选择界面部分资源暂用原版占位数据；正式爆裂玩法尚未接入。
