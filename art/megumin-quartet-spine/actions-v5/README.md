# 惠惠 · 侧身单手伸杖与关节修正 v5

[播放动画](preview.html) · [九帧对照](keyframes.html) · [54 帧过程检查](review-frames.html) · [Spine 导入包](megumin-actions-v5-import.zip)

2026-10-09。针对 v4 的肘膝弯折问题继续修订，并按用户指定的参考 A03，将爆裂预备改为侧身、右手单手前伸杖、左臂向后下方展开。待机的绘图和运动保留。v4 留在相邻目录，可直接比较。

交付为 Spine 4.2.11 JSON：25 根骨骼、28 个插槽、18 段动作和一个静态检查片段，12 张图集页。离线 `preview.html` 内嵌官方 Spine WebGL 4.2.95 运行库、绘图和数据，不需要启动服务。

## 本轮修改

| 问题 | 修改 |
|---|---|
| 吟唱中右肘折回肩旁，约 168° | 右手握点前移，保持约 23° 的轻微弯曲；左手不再搭杖 |
| 爆裂预备仍为正面双手姿势 | 补画侧身头部、躯干；后侧肩臂后收，右臂前伸，头身同向；吟唱、释放和取消采用一致姿势 |
| 爆裂卸力、起身、死亡时膝盖在深屈曲中反向 | 只在腿伸直、两种解重合时切换膝盖方向；下降和起身全程保持同一弯曲方向 |
| 下蹲时髋部与脚踝挤在一起 | 新增躯干旋转骨，骨盆与上身前倾分离；重排深蹲、坐倒和脚的位置 |
| 倒地、起身时握点穿过肩部附近，肘部突然翻折 | 右手沿肩部周围的弧线移动，分别插值角度和距离，避开两段骨骼无法稳定求解的区域 |
| 撑地后上身抬起过快 | 增加收腿、弯腰承重的中间姿势；先撑地、再收腿抬手、握回法杖、逐步站稳 |
| 后展左臂被旧披风覆盖 | 修复插槽附件键覆盖透明度键的问题；侧身披风、后臂、前侧衣服分层，左手与杖尾拉开 |

参考为 [A03 官方剧照](https://isekai-quartet.com/assets/story2/3_6.jpg)，本地见 `../../isekai-quartet-references-20261009/originals/A03-s2-e03-6.jpg`。采用其中的单手送杖及另一臂后展关系，转换为游戏中朝右的侧身构图；没有水平镜像角色、交换左右手或移动眼罩与绷带的归属。

## 检查结果

使用实际导出的 Spine 数据检查，不以作者姿势参数代替运行时结果。

- [关节检查](joint-audit.json)：以 240 Hz 采样 6,339 个时刻，检查肘膝角度、相邻采样的关节位移和屈曲时反向。v5 无越界项。150° / 3 像素是本项目筛查阈值，不是通用人体生理标准。
- 起身右膝的最大相邻采样位移从 v4 的 **47.85** 降到 **1.51** 世界像素；左膝从 **45.74** 降到 **1.07**。此数字包含正常移动，不等于全是跳变。
- [运行时验证](export/validation.json)：3,181 个时刻检查 IK 到点、有限坐标、肢体伸长、落地网格、四个循环、14 处片段衔接、单手姿势、撑地手掌和事件次数，全部通过。
- 与 v4 的待机逐顶点比较，最大差异约 **0.0000153** 世界像素，为浮点误差量级。待机脚、法杖锚点没有漂移。
- 起身左掌在 0.46–0.86 秒保持支撑，漂移约 **0.040** 世界像素。一次身体释放对应一个 `release` 事件。

数值筛查不代替美术判断。请在预览中慢放、拖帧或打开骨骼，查看中间过程；54 帧页面展示六组动作。

## 美术、导入与复现

新增的 [侧身分件](source/side-parts.png) 使用内置 image_gen 生成并进行一次转向修订，最终 [提示词](source/side-parts-prompts.txt) 已保存。仅在转身动作中切换侧身头、衣服和局部表情；已认可的待机继续使用原图。其余分件继承 v4，来源与提示词保留在 `source/`，哈希写入 `export/manifest.json`。

Python 负责 UV 几何切分、骨骼与时间线、原像素图集装箱，不用代码重绘源图。手臂弧线、关节方向与接地均已烘焙到标准 Spine 数据，不需要额外运行时修正脚本。

在 Spine 4.2 编辑器通过 Import Data 读取 `export/megumin.json`，图片路径为 `../images/`。运行时读取 `export/megumin.json` 或同内容的 `.spine-json`、atlas 与 12 张 PNG 图集。保留 mipmap 缩小过滤设置。

尚未在原生 Spine 编辑器或 STS2 游戏内验证。当前是含侧身替换分件的二维动画，不是完整多角度逐帧动画；没有提供伪造的 `.spine` 工程或 `.skel` 二进制文件。

在上级目录运行：

```powershell
npm run build:actions:v5
npm run test:actions:v5
```

构建顺序：`build_actions_v5.py` / `actions_v5_overrides.py` → `bake_floor_v5.mjs` → `validate_actions_v5.mjs` → `audit_joint_logic.mjs` → `package_actions_v5.py` → `build_review_v5.py`。旧版问题可用 `node tools/audit_joint_logic.mjs actions-v4 --strict` 复现；此命令预期报告失败。
