## 本版内容

- 13 张实际用于绑定的独立姿势图，63 根骨骼、11 个槽、131 个附件。
- 19 个动作，另有 13 个 `_bind/` 辅助姿势。绑定姿势用于编辑，不是玩法动作。
- 进入吟唱 1.30 秒：原右手收肘、转向、向前送杖。大幅转向采用替换绘图；过脸阶段法杖在头后方绘制。
- 脱力趴地 1.40 秒：屈膝、左掌缓冲、胸腹朝地。起身 3.67 秒：抬身、收膝、站稳、收杖。
- 一根独立刚体法杖，固定在右手；倒地受击与倒地死亡保留趴地状态。

这里的 60 FPS 表是运行时采样，**不是每秒 60 张手绘参考图**。`references/` 还保留较早的候选图，只有 `authoring.json` 中的 13 个姿势参与当前绑定。参考图中的法杖细节不完全一致，运行时统一为独立的 `staff-master`。

## 复查方法

直接打开 `preview.html`，无需服务器。上方选择动作，播放、慢放、输入时间或单步翻帧。左侧为当前附件对应的参考图，右侧为官方 Spine WebGL 4.2.95 的实际输出。可以叠加参考、显示网格/骨骼，或切到深色背景和 320 px 画布。

下方对照表有“关键姿势”和“换图前一帧 / 换图帧 / 后一帧”两种范围。检查中间过程时使用后者；只看关键姿势会漏掉错误。完整流程最后返回待机。

## 验证范围与剩余边界

官方 Spine Core 4.2.95 完成 3511 个时间点采样，检查所有附件、有限坐标、原图绑定误差、右手握点、法杖刚性、5 个循环、17 处衔接、单次释放事件和死亡定格。结果在 [validation.json](export/validation.json)。

浏览器复查覆盖进入吟唱、释放后卸力、跪撑到趴地、撑地起身及换图邻帧。**本版仍是动作复查素材**：不同绘图之间还有局部轮廓与衣褶变化，撑地与落脚的重量感还可以继续精修。网格反折指标包含透明三角形，只用来筛查大变形，不代表美术合格或脚掌接地已被精确约束。

尚未实测 Spine 编辑器导入、原生 Godot 运行库或 STS2 游戏接入；不把 JSON 称为已经制作完成的 `.spine` 工程或 `.skel`。

## 导入

1. 完整解压导入包，保持 `export/` 与 `images/` 同级。
2. 用 Spine 4.2 的 Import Data 打开 `export/megumin.json`。
3. JSON 的图片目录为 `../images/`。这些是原始尺寸、未加图集边距的源图片；全部附件路径均已核对。
4. `_bind/` 可用于检查每种姿势的绑定。编辑器重新导出时应将它们排除玩法资源。
5. Godot 的 `megumin.spine-json` 与 JSON 内容一致；正式 `.spine` / `.skel` 需在对应编辑器中保存、导出并验证。

包内含绘图参考、生成提示词、逐帧表、图集与源图、指引和验证报告；**不包含原版 STS2 角色研究素材**。离线预览保存在包外的 `preview.html`。

## 重建

在 `art/megumin-quartet-spine/` 下执行：

```powershell
py -X utf8 tools/build_actions_v7.py
node tools/validate_actions_v7.mjs
py -X utf8 tools/package_actions_v7.py
```

Python 需要 NumPy、Pillow、Shapely、mapbox-earcut（当前工作区 `.build-deps` 可用）；Node 依赖锁定在上级 `package-lock.json`。构建只复制图像像素并生成网格、骨架和时间线，不重绘原图。

`tools/choose_v7_switches.mjs` 是可选作者工具，会更新 `attachment-switches.json`，因此重新选择切换点后必须再构建、验证、看画面。默认构建使用随版本保存的切换点。
