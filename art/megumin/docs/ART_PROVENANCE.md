# Megumin artwork v1 / 美术来源与质量说明

所有角色位图均使用内置 image_gen 生成或同源编辑；未使用 CLI/API 备用图像生成，也未用 SVG 代替人物美术。

## 已确认与暂未确认
- 角色：惠惠，短深色头发、红眼、法师尖帽、红衣、深色金边披风、红宝珠木杖
- 方向：朝画面右侧；持杖侧和自由手在全部运行姿态中保持一致
- 首版自主建立素材规格，因为目标项目目前为研究资料阶段，未有正式画布/锚点/工程
- 本交付为独立美术与 Godot 动画演示，不表示已接入 STS2 或验证了游戏伤害时点
- 参考了已提供的制作经验：先验关键姿势、脚底固定、局部关节动画、独立披风循环、保持死姿、结束回待机

## 原始图像
- 站立：1024×1536 RGBA，原始完整数据保留；右上杖外缘接近画布，运行素材用独立完整杖层修复
- 脱力：1536×1024 RGBA，角色跪地并扶杖，作为专用姿态而非独立风格重绘
- 倒地：1536×1024 RGBA，横向终态，闭眼无伤口，保持最终倒地画面
- 补底：1024×1536 RGBA，同源去双臂/披风/法杖版本，仅用作被遮挡衣服的小范围补底
- 法杖：1024×1536 RGBA，独立完整杖层；配准以宝珠/握点为准，补全底端不等于改变原杖长度

## 透明性验收
原始图像预览可能显示保留在RGB通道里的彩色背景，但 alpha 合成后这些区域完全消失。已分别在灰白棋盘和深蓝色背景上合成检视站立、脱力、倒地三张：无背景矩形、无烟雾、孔隙透明，人物主色视觉稳定。

保留内置生成器原始 alpha。主体 alpha 多为253/255（约99.2%），最大254；未宣称全部像素255，也未任意二值化破坏抗锯齿。数值见 quality/alpha_report.json。

## 动画方法
同源纹理分件和关节网格用于主体动态；复杂遮挡姿态使用专门生成的跪姿/倒地画面。角色动画渲染是确定性的，原始PNG不做手工美术重绘。倒地姿态切换不声称为完整 Spine 骨骼物理倒地。

## 迭代边界
需要目标工程接线后，才可验证RitsuLib状态名称、角色战斗占位、伤害触发及复活/死亡流程。当前Godot演示验证仅覆盖本素材自身。最终用户可决定眼罩/绷带是否常驻及角色比例风格调整。
