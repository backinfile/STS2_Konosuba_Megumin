# 六状态计划（设计目标，尚未完成）

| 状态 | 动作目标 | 结束行为 |
|---|---|---|
| Idle | 自然站立，轻微呼吸、披风延迟跟随，膝松弛 | 无缝循环 |
| Cast | 沉肩收势、抬肘举杖、吟唱蓄能，靠姿势可读 | 收回到Idle；独立状态不假设跨回合玩法 |
| Attack | 完整收势/举杖吟唱/蓄满停顿/向右爆裂释放/后坐/收回主链 | 回Idle；标注建议impact事件供接入时核验 |
| Hit | 肩胸短促后仰，肘腕随动，脚底支持不滑 | 回Idle |
| Relaxed | 爆裂后膝松/头肩下垂与手杖下沉，随后恢复 | 回Idle |
| Dead | 明确失去支撑的末态，不自动站起 | 停终态；需独立检查遮挡与出界 |

不把六状态API存在视作对应美术已经验收。主链无特效可读后才补状态；未完成状态必须标注。

伤害触发只是动画建议时间，不能据此声称STS2伤害已正确同步。位移需有重心与肢体变化，不以整张立绘抖动替代。
