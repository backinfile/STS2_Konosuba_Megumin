# v3美术与纹理检查

本版以同一张惠惠母图的头、手、四肢及同一根法杖作持续关节动画，没有在六张全身姿态图之间瞬切或交叉淡入。

仅新增两张由内置image_gen生成的遮挡补底：
- 保持母图构图的无臂胸腹、肩袖根和披风
- 独立完整披风，补全原身体和腿遮住的布料

原始文件均保留，没有以模糊或拉伸肢体隐藏接缝。补底只承担肩腋和背后遮挡，头与手仍来自固定母图。

两张新增补底均为1024×1536 RGBA，已经使用Mi-Ripple进行整图检测并目视原尺寸衣服/披风：未检测到工具支持的周期网格伪影，结果为no-op；因此保留原像素及透明通道，不把无变化称为去纹成功。先前同源素材用GPT Image 2 Artifact Cleaner的低强度对比显示细节变软而收益不足，本版不强制进行全图平滑。工具和模型不包含在角色工程中。

关键制作约束：全程固定头/手/骨长度与角色比例，双脚底锚点不滑动；正常待机近自然直立，屈膝仅在动作阶段，末尾回同一站姿；披风及袖摆可作为独立衣料跟随，不能改变肢体尺寸。

预览仍为Godot真实时间轴、网格和变换数据的离线软件光栅结果，非Godot图形后端实录。没有为录制启动网络监听。Godot图形后端与STS2游戏内接入需在可用环境进一步验证。
