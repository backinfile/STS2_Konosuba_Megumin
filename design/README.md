爆裂（类似力量的Power）：“回合结束时，如果本回合没有主动打出任何卡牌，则消耗全部爆裂对所有敌人造成等量伤害。”默认1次。旧吟唱计数、爆裂魔法生成与逐张减费，不作为当前核心。

技能牌体系优先补下回合格挡、格挡保留等保护。红魔族宣言仍是10张以内的小体系，关键词为“连续打出3张技能牌触发后续效果”，主要在准备回合提供抽牌与能量。

魔力积蓄：“选择1张手牌放入魔力积蓄，下回合开始自动将其打出（消耗能量）”。能量不足等执行细则待定。技能点仍是类似金币的少量全局点数，用于额外获取卡牌，具体规则待设计。
