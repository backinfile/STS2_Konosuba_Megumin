## 2. 职业设计上下文
惠惠为爆裂核心；强项为爆发和持续战场影响，弱项为前置投入与脱力窗口。队友题材提供保护、运转与有限恢复。先按单人闭环设计，多人规则仅记录边界。每个候选主轴必须覆盖攻防运转，至少两个可构筑分支，至少三张非稀有抽牌牌。高复杂核心不叠加其他复杂资源。

## 余波：阶段1—5结果

- 阶段1：大体系候选；资源生成、维持、支付与自然衰减都有牌间需求，覆盖三端口。
- 阶段2：爆裂创建余波 → 选择维持或支付 → 获得输出／防护／运转 → 通过防御与滤牌撑过脱力 → 再爆裂。拿到看清烟尘后更愿意保留自然衰减；拿到最后的轰鸣后更愿意抓即时增层与保护。
- 阶段3：五项突破候选审查，保留三项；详见HTML及结构化卡表。
- 阶段4：16张奖励牌，普通 6 / 罕见 7 / 稀有 3；攻击 3 / 技能 9 / 能力 4；非稀有抽牌4张。
- 阶段5：同一助手六视角纸面审查，结构局部通过。
- 核心来源：WAVE-05／08／13补层；WAVE-04维持但不直接触发。基础爆裂提供3层。回合末自动伤害与实际减层，是不依赖手动出牌的扳机；WAVE-08在脱力回合开始被动补层。
- 端口：输出：01、05、11、12、15及基础余波；防御：02、07、11、16；运转：03、06、09、10、13。无稀有也有三端口，稀有只抬上限。
- 排除／降级：普通治疗、任意群攻、所有队友卡不是自动的余波成员。此前“替你挡住”不读取也不影响余波，移到通用支援，而不是占用体系卡位。
- 待测：固定3层，比较消耗1层防御与不消耗；再固定6层比较轰鸣和自然衰减。必须出现不同场面下选择反转。
- 剩余风险：常明＋庇护可能形成低成本慢磨；场地输出总量随层数非线性增长。没有结构性无限不等于强度合理。

## 裂地：阶段1—5结果

- 阶段1：大体系候选；等级来源、首攻载体、首攻收益与攻防转换形成需求。
- 阶段2：爆裂建场 → 抓首攻载体与防护 → 主动施放或完整格挡推进等级 → 每回合选择高价值首攻／转为防御 → 用触发后抽牌支持下一轮。
- 阶段3：五项突破候选审查，保留三项；详见HTML及结构化卡表。
- 阶段4：16张奖励牌，普通 6 / 罕见 7 / 稀有 3；攻击 3 / 技能 9 / 能力 4；非稀有抽牌4张。
- 阶段5：同一助手六视角纸面审查，结构局部通过。
- 核心来源：基础爆裂、CRATER-07敌方攻击后被动升级、08付费升级；01、04与其他攻击是首攻事件载体。07需要已有裂地且本场只生效一次。
- 端口：输出：01、04、09、12—15；防御：02、06、10、16；运转：01、03、05、06、11、13。大量运转集中11兑现后抽牌和01／03／06，不自动返还能量。
- 排除／降级：单纯净化、所有攻击牌、所有带格挡牌不自动属于裂地。“稳住阵脚”移入通用层；落点确认是中坚素材而非来源扳机。

- 剩余风险：满级之后每回合默认先群攻可能固定化；07与08减少重复爆裂的必要性。需要比较删掉第二发后是否反而更高效。

## 回响：阶段1—5结果

- 阶段1：大体系候选；待结算事件作为专属对象，创建、编辑、结算和结算收益相互支持。
- 阶段2：爆裂安排两道回响 → 用调度牌提前／延迟 → 自动结算提供输出与监听收益 → 抽牌找保护和下一批调度 → 再次爆裂或通过回音壁延续衰减事件。
- 阶段3：五项突破候选审查，保留三项；详见HTML及结构化卡表。
- 阶段4：16张奖励牌，普通 6 / 罕见 7 / 稀有 3；攻击 2 / 技能 11 / 能力 3；非稀有抽牌5张。
- 阶段5：同一助手六视角纸面审查，结构局部通过。
- 核心来源：基础爆裂；ECHO-05在已有事件时追加小事件；04／07／12修改既有事件；自然到期不依赖主动出牌。15把已结算事件被动转为衰减来源。
- 端口：输出由05、07、12及事件提供；防御02、08、10、11、13；运转01、03、06、09、12。09在自动结算后抽牌，06提供非稀有集中运转。
- 排除／降级：所有延迟效果并非同一体系；一般“下回合能量”不是回响事件。芸芸普通补刀改放通用牌，不用“发生在回响期间”硬贴归属。
- 待测：对同一个12伤害事件做提前、延期、合并，校验只结算一次；再测试16＋15只衍生一个下回合事件，不递归立即结算。
- 剩余风险：易伤与场地伤害的区分可能违背直觉；多能力启动后自动抽牌与格挡可能压倒时间取舍。还未验证当前伤害预算。
