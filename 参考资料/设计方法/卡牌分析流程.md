# 卡牌分析流程

本文用于规范“分析一个职业卡池”的工作流程。目标不是重新列出所有卡牌，而是从卡池结构、体系分布和关键核心牌三个角度，提炼出可复用的设计结论。

## 输入资料

- 职业卡牌表：包含稀有度、类型、费用、名称、效果、升级后效果。
- 职业体系文档：已经按体系整理过卡牌角色、端口、触发牌、收益牌与跨体系牌。
- 体系判定标准：参考 `docs/体系分析流程.md`。

## 分析流程

### 1. 卡池基础结构

先统计整个职业卡池的基础分布，用来判断这个职业的默认节奏和卡池偏向。

需要统计：

- 各稀有度的卡牌数量。
- 每个稀有度下的卡牌类型分布：攻击、技能、能力。
- 每个稀有度下的升级前费用分布：0、1、2、3、X。
- 全卡池的类型总分布与升级前费用总分布。

统计时注意：

- `1->0`、`2->1` 这类牌按升级前费用统计，例如 `1->0` 计为 1 费，`2->1` 计为 2 费。
- `X` 费单独统计。
- 基础牌要保留，但在判断职业奖励卡池倾向时可以单独说明。

结论只保留能解释职业结构的点，例如：

- 低费牌是否明显偏多，是否支持多牌连打。
- 高费牌主要集中在哪种类型，是否对应终结牌或能力牌。
- 能力牌集中在哪个稀有度，是否说明核心规则主要通过稀有牌建立。
- 攻击、技能、能力比例是否暗示职业偏输出、防御、运转或能力启动。

### 2. 体系结构分析

再根据职业体系文档统计每个体系的内部结构。

每个体系需要统计：

- 体系卡牌总数。
- 稀有度分布。
- 类型分布。
- 升级前费用分布。
- 体系内角色分布：机制引导牌、机制基础牌、机制核心牌、突破限制牌、机制中坚牌。
- 机制触发牌数量。
- 机制收益牌数量。
- 触发+收益牌数量。
- 跨体系牌数量。
- 输出端、防御端、运转端覆盖情况。

统计口径：

- 机制触发牌 = `扳机触发` + `触发+收益`。
- 机制收益牌 = `扳机收益` + `触发+收益`。
- 跨体系牌可以和触发牌、收益牌重叠，不从总数中扣除。
- 一张牌如果属于多个体系，在各体系中分别计数，并记录它在该体系里的角色。

#### 体系内角色分类

体系内每张牌还需要按选牌功能继续分类。这个分类用于判断体系入口是否清晰、基础触发是否充足、核心奖励是否集中，以及是否存在能改变构筑上限的关键牌。

分类优先级：

1. 先判断是否为突破限制牌。
2. 再判断是否为机制引导牌、机制基础牌或机制核心牌。
3. 不符合上述条件的体系相关牌，统一归为机制中坚牌。

同一体系内，每张牌只归入一个分类。

| 分类 | 判定标准 | 选牌含义 |
| --- | --- | --- |
| 机制引导牌 | 稀有度为普通或罕见；吃到本体系扳机后有明显收益；没有扳机触发牌时抓了也不亏；抓到后会鼓励玩家继续找更多扳机触发牌 | 体系入口牌，玩家看到后能大致理解这个体系的玩法 |
| 机制基础牌 | 稀有度为普通或罕见；属于扳机触发牌；单独抓取不亏；效果一般是制造体系扳机，同时造成伤害或获得格挡 | 体系燃料牌，负责提供稳定触发和基础数值 |
| 机制核心牌 | 属于扳机收益牌；没有稳定扳机触发时抓了会亏，表现为数值低、效果打不出或收益不稳定；一旦有稳定扳机就能获得高收益 | 体系奖励牌，决定玩家是否真正进入该体系 |
| 突破限制牌 | 一般为稀有牌；效果唯一，且极其契合本体系机制；通常一张牌就解决输出、防御、运转三个端口中的某一端 | 体系上限牌，改变构筑能力边界 |
| 机制中坚牌 | 与体系有关，但不满足引导、基础、核心、突破限制的牌 | 体系补强牌，补数量、补端口或提供跨体系连接 |

分类时注意：

- 机制引导牌通常既能独立发挥作用，又能提示玩家“继续抓触发牌会更强”。
- 机制基础牌重点看是否稳定制造体系扳机，不要求它自身吃到扳机收益。
- 机制核心牌重点看是否依赖体系扳机；没有扳机时越弱，有扳机时越强，越接近核心牌。
- 突破限制牌不只是强牌，而是突破体系原本缺口或规则限制的牌。
- 跨体系牌在不同体系中可以有不同分类。

分析重点：

- 触发牌和收益牌是否成对存在。
- 体系是否过度依赖少数稀有牌。
- 体系是否有清晰的机制引导牌，让玩家在普通/罕见阶段看懂构筑方向。
- 体系是否有足够机制基础牌，保证扳机来源稳定。
- 机制核心牌是否过度集中在稀有牌，导致体系成型过晚。
- 体系是否缺输出、防御或运转端。
- 普通牌是否能提供稳定入口，罕见/稀有牌是否提供构筑奖励。
- 跨体系牌是否把两个体系自然接到一起，而不是只做功能拼接。

### 3. 查找“突破限制”牌

“突破限制”牌是一个体系中最值得单独记录的核心牌。它通常不是单纯数值强，而是打破该体系的常规限制，让原本有限的资源、触发次数或收益方式产生质变。

优先从以下牌中筛选：

- 能把体系资源从一次性收益变成持续收益的牌。
- 能把防御端转化为输出端，或把输出端转化为运转端的牌。
- 能让体系触发次数显著增加的牌。
- 能绕开费用、抽牌、手牌数量、回合结束、格挡清空等常规限制的牌。
- 效果在本职业内高度唯一，并且只在本体系中最能发挥价值的牌。
- 一旦出现就明显改变选牌、删牌、升级和遗物需求的牌。

不要把以下牌轻易标为“突破限制”：

- 只是同类牌里数值更高的终结牌。
- 只是普通的抽牌、能量、格挡或伤害牌。
- 需要大量外部条件，但本职业内缺少稳定配套的牌。
- 效果独特但不改变体系构筑方式的孤立牌。

记录时只保留：

- 卡牌名称。
- 所属体系。
- 突破了什么限制。
- 为什么它是体系核心。
- 补足了哪个端口：输出、防御或运转。
- 依赖条件或风险。

### 4. 非流派单卡分析

最后统计没有进入任何体系的单卡，用来观察职业卡池中独立功能牌、强数值牌、一次性工具牌和多人/特殊规则牌的设计特点。

这里的“非流派单卡”指：

- 没有出现在职业体系文档任一体系表中的牌。
- 可以属于“不单列为体系的功能标签”，但没有围绕某个明确核心形成扳机收益闭环。
- 可以服务某些体系或端口，但自身不构成体系入口、基础触发、核心奖励或突破限制。

需要统计：

- 非流派单卡总数。
- 稀有度分布。
- 类型分布。
- 升级前费用分布。
- 每张非流派单卡的功能定位与设计特点。

每张牌至少记录：

- 卡牌名称、稀有度、类型、费用。
- 功能定位：例如纯数值输出、牌堆操控、抽牌爆发、费用作弊、随机生成、回复、长期经济、多人保护等。
- 为什么不算体系：缺少共同核心、缺少扳机收益、只提供一次性功能、只服务其他体系等。
- 设计特点：这张牌在卡池里解决什么问题，或者提供什么独特体验。
- 风险或依赖：例如随机性、费用偏高、需要特定手牌结构、多人环境依赖、只适合短战斗等。

分析时注意：

- 不要为了覆盖所有牌而强行新增体系。
- 非流派单卡不是“无用牌”，它们通常承担补洞、爆发、泛用运转、稀有奖励或特殊玩法调味。
- 如果多张非流派单卡共享一个功能标签，也只能记录为功能组；除非它们形成明确扳机与收益闭环，否则不要升级为体系。
- 重点观察这些牌如何补充职业体验：是提高稳定性、提供终结爆发、增加随机性，还是服务多人模式。

## 最终输出要求

最终结果要精简，不保留完整卡牌列表。详细中间表可以用于分析，但不写入最终报告。

### 5. 总结结论

只保留 3 到 6 条结论，优先回答：

- 这个职业的主体系是什么。
- 哪些体系是成熟体系，哪些只是副轴或效果组。
- 职业的卡池入口是否充足，核心奖励是否过度集中在高稀有度。
- 职业最重要的突破限制牌是什么，它们如何改变构筑方向。
- 非流派单卡主要承担哪些补充职责，是否暴露出职业缺口或设计偏好。
- 后续设计新卡时，最值得补强的是触发端、收益端、运转端还是防御端。

## 输出风格

- 少写单卡描述，多写统计和结论。
- 不重复体系文档中的完整表格。
- 每个体系最多写一句核心判断。
- 突破限制牌宁缺毋滥，优先保证“唯一性”和“构筑改变能力”。
- 非流派单卡可以逐张记录，但每张只保留功能定位和设计特点，不展开完整效果复述。
- 如果一个结论不能指导后续卡牌生成或体系补强，就不要写入最终结果。
