# 新角色 Mod 通用设计指南

> 面向《杀戮尖塔》类牌组构筑游戏的新角色设计。覆盖角色定位、机制、卡池、单卡、遗物、药水、多人协作与平衡迭代。本文只讨论玩法与体验。
>
> 本指南从原版职业与角色 Mod 的卡牌研究中提炼方法。数量与比例是规划参考，具体角色仍应围绕自己的玩法作取舍。

## 一、先确定玩家要体验什么

一个新角色首先需要一种值得反复体验的决策方式。题材、人物形象和华丽效果能吸引玩家，持续的选择才让玩家愿意再开一局。

角色立项时，先写出下面五项。

| 项目 | 要回答的问题 | 示例：以“储备与释放”为主题的角色 |
| --- | --- | --- |
| 核心体验 | 玩家主要在做什么？ | 储存本回合暂时不用的资源，寻找释放窗口 |
| 核心矛盾 | 为什么不能永远采取同一种做法？ | 现在使用能减少损血，继续储存能换取更大回报 |
| 优势 | 熟练玩家能做出什么令人满意的事情？ | 提前准备，在关键回合集中兑现 |
| 弱点 | 玩家需要承担什么压力？ | 准备期间战力不足，提前释放会失去成长机会 |
| 成长方向 | 不同对局能怎样玩出区别？ | 快速周转、长期囤积、少量储备辅助常规攻防 |

尝试用一句话概括角色：“玩家通过____，在____与____之间选择，最终获得____。”

“攻击很强”“有很多流派”“拥有独特能量”还不足以回答这个问题。它们描述能力或内容，需要继续解释玩家会作出什么不同的决定。

### 主题要进入操作过程

擅长预判的角色，可以让玩家安排未来抽牌或预留反制；强调牺牲的角色，可以把失去某种资源转化为其他收益；强调变化的角色，可以让同一张牌在不同阶段承担不同职责。

如果去掉卡名和插画后，角色完全变成通用伤害、格挡与抽牌的集合，主题还没有充分进入玩法。反过来，也不必让每张牌都讲述剧情：简单、好用的战斗工具同样是角色体验的一部分。

## 二、选择一个能反复产生选择的核心机制

### 1. 从资源、事件或专属对象出发

| 机制来源 | 设计时重点考虑 | 可产生的选择 |
| --- | --- | --- |
| 资源 | 如何获得、储存、花费、流失 | 现在消费还是积累；换输出还是换防御 |
| 事件 | 什么行为发生时获得收益 | 主动制造事件，还是等待自然发生 |
| 牌的位置 | 不同位置是否改变用途 | 立即打出、暂存、弃掉、回收或移出循环 |
| 专属对象 | 如何生成、培养、使用、失去 | 少量精养还是大量消耗；保护还是牺牲 |
| 时间与阶段 | 收益什么时候到来 | 承受当前压力换未来收益；提前兑现还是继续等待 |
| 卡牌特征 | 哪类牌会改变彼此价值 | 围绕低费、多段、生成牌或某种标签重新构筑 |

优先寻找与现有战斗行为能自然结合的机制，例如出牌、弃牌、消耗、失去生命、获得格挡。专属机制可以很新，但玩家应当能用熟悉的行动接近它。

### 2. 为机制写清四件事

- **来源：** 玩家通过什么获得资源或制造事件？
- **用途：** 它如何改善输出、生存或运转？
- **限制：** 什么阻止玩家无条件反复获利？
- **变化：** 成型后可以怎样改变原有使用方式？

只有来源，没有值得追求的收益，玩家会觉得自己一直在准备。只有收益，没有可靠来源，玩家会觉得卡牌永远缺另一半。

### 3. 优先挖掘同一机制的不同用途

同一种资源可以支持积累、花费、保留、清空、转化等方向。它们共享基本规则，却要求不同的出牌顺序和选牌判断。

例如，一个“储备”机制可以同时奖励高库存、频繁存取和一次清空。玩家不能在同一时刻满足所有目标，选择因此成立。

不必为每条路线新增一个计数器。多个机制若来源相同、花费方式相同、最后都换成伤害，可能只是重复包装。

### 4. 控制复杂度预算

如果主机制需要理解额外区域、跨回合状态或变化规则，副机制就应尽量直观。不要让每张普通牌都引入例外，也不要把理解核心玩法所需的说明藏在稀有牌里。

新关键词应当服务反复出现的规则。只出现一两次、用普通动作就能说清的效果，通常不值得再增加术语。

## 三、把机制组织成真正的构筑体系

一个体系应当让牌与牌互相产生需求。拿到一张收益牌后，玩家会更想拿某些来源牌；拥有足够来源后，又会更重视兑现方式。

“这些牌都造成群体伤害”“这些牌都抽牌”通常只是功能分类。只有当它们围绕共同资源或事件产生配合，才有理由称为体系。

### 体系的六种角色

| 卡牌角色 | 设计任务 | 判断问题 |
| --- | --- | --- |
| 入口 | 让玩家愿意开始尝试 | 没有完整配套时，为什么可以拿？ |
| 来源 | 稳定提供资源或触发机会 | 获得收益牌后，能否持续供给？ |
| 收益 | 奖励玩家围绕机制构筑 | 做同样的事情，为什么现在更值得？ |
| 连接 | 让两条路线共享价值 | 一个体系的行为如何成为另一个体系的材料？ |
| 突破 | 改变原有边界 | 容量、持续性、费用、时机或用途改变了什么？ |
| 终结 | 把准备转化为胜利 | 玩家靠什么结束战斗，而非永远运转？ |

一张牌可以兼任多个角色，但不宜让大多数牌都同时提供来源、抽牌、能量、输出和防御。否则抓牌失去取舍，体系也不再需要组合。

### 主体系、副体系与通用牌

主体系应当能承担主要获胜计划，并通过自身或连接牌解决生存与运转。副体系可以只提供爆发、续航或工具，不必独立完成所有任务。

设计初期可以先探索一到两个主机制，以及少量副方向。原版职业既有围绕一个大机制展开的设计，也有多个主轴并存的设计，体系数量不需要统一。

保留一批通用牌来解决即时问题：可靠攻击、群攻、防御、减益、抽牌、回收等。它们让玩家在配套尚未齐全时继续前进，也允许混合构筑存在。

### 好的连接会改变拿牌理由

例如，“每次攻击附加中毒”会让多段和生成攻击牌成为中毒来源；“把格挡转成伤害”会让防御投入成为进攻准备。连接应改变两类牌的关系。

同一张牌分别给予两种互不相干的资源，也可能是实用工具，但不能仅凭同时出现两个关键词就称为深度联动。

## 四、规划完整卡池

### 1. 先列功能需求，再分配卡位

先列出角色需要解决的问题，再判断由哪些牌承担。不要从“我要写二十张攻击”开始逐格填效果。

| 必须覆盖的问题 | 典型职责 | 常见遗漏 |
| --- | --- | --- |
| 早期击杀 | 可靠单体输出、适量爆发 | 所有攻击都需要先启动能力 |
| 多敌战 | 群体伤害、分散打击或控制 | 单体成长很强，却没有处理多个敌人的办法 |
| 稳定生存 | 格挡、减伤、敌方削弱等 | 防御全部依赖一张稀有核心 |
| 运转 | 抽牌、筛选、检索、回收、费用管理 | 有很多资源，却找不到需要的牌 |
| 长战成长 | 持续增益、资源积累或循环效率改善 | 前两回合很强，之后迅速失去战斗能力 |
| 终结 | 爆发、持续伤害兑现或特殊胜利条件 | 能无限准备，却无法有效结束战斗 |
| 不顺时的过渡 | 通用牌、替代入口、混合路线 | 没抽到指定组合就没有可玩的牌组 |

一个职责可以有多种解决方式，不必每项都用最直接的数值牌完成。

### 2. 总量与统计口径

若目标是接近原版体量，应先确定目标版本和单人、多人范围，再对齐常规奖励规模。不要把某个版本的固定总数当作所有新 Mod 的永久标准。

基础牌按种类与起始张数分别记录；普通、罕见、稀有构成常规奖励部分；衍生牌、诅咒、特殊来源牌另列。多人限定牌也应单列，避免总数齐全而单人选择不足。

作为早期规划起点，可以让通用与过渡工具占据约五分之一左右的卡位，其余交给主机制、副方向和连接。这个比例只帮助预留空间，不用于判定设计合格与否。

### 3. 稀有度分工

| 层级 | 主要任务 | 应避免的倾向 |
| --- | --- | --- |
| 基础 | 让第一场战斗成立，展示最小核心体验 | 承担复杂成型责任，或只展示优势而没有决策 |
| 普通 | 提供战斗骨架、机制入口和稳定来源 | 每张都等待配套，或每张都有长篇特殊规则 |
| 罕见 | 提供收益、连接、定向工具与第一批持续规则 | 只是普通牌数字更大，却没有新拿牌理由 |
| 稀有 | 提供独特机会、强终结、规则突破或显著取舍 | 被迫承担所有基础生存，或无条件替代低稀有牌 |
| 特殊来源 | 配合获取情境提供非常规体验 | 混入常规奖励强度与密度比较 |
| 衍生牌 | 为来源牌提供后续行动 | 脱离生成费用和取用条件单独评价 |

普通牌以容易使用的攻击和技能为主体，是很稳妥的起点。稀有牌可以简单而强，并不要求每张都增加一条新规则。

### 4. 费用与类型服务实际回合

费用曲线需要和抽牌、额外能量、资源储存、自动打出、减费等能力一起看。低费多未必有问题，高费少也不一定缺内容。

零费牌仍消耗一次抽到它的机会；高费牌应提供与投入相称的节奏变化；X 费适合承接可变资源，但需要明确资源从哪里来、最终怎样兑现。

能力牌不直接完成当回合攻防。评估时应检查一手同时抽到数张能力的局面，而非只评价全部启动后的理想状态。

## 五、起始卡组与起始遗物一起设计

起始体验要让玩家在前几场战斗中完成一次最小机制循环：获得材料，作出选择，看到收益。

基础攻击与防御提供可靠底座，少量机制牌展示角色操作。起始遗物可以保证最低限度的入口或强化第一次体验，但不应替玩家完成全部判断。

检查以下情境：机制牌先来、后到、两张配套分开抽到、首回合受到高压、玩家第一次使用时作出不理想选择。只有固定顺序才能正常运作的开局过于脆弱。

还要设计“毕业”：玩家后期应当有理由替换基础牌、调整初始操作方式，或让初始工具获得新用途。起始组合若天然覆盖所有需求，奖励牌会失去吸引力。

## 六、设计一张值得存在的卡

### 1. 先回答它为什么占一个卡位

候选牌至少应满足一种价值：解决此前缺少的战斗问题；创造新的时机选择；让旧牌有新的用途；为另一类牌提供清晰连接；表达一个具有操作意义的主题。

最重要的比较对象往往是本角色中最相似的牌。分别写出“什么情况下选这张，而不是另一张”。如果答案只有数字高一点，考虑合并、替换或改变职责。

### 2. 同机制牌应有不同使用情境

同一个机制可以出现在攻击、防御和运转牌上，也可以跨越不同费用。共享规则能帮助学习，不代表重复。

差异应落在玩家能感受到的地方：即时效果、来源区域、选择自由、等待时间、目标范围、可重复性或承担的风险。不要为了制造差异，随意增加一个无关条件。

效果相反也不一定重复。奖励囤积和奖励清空可以形成很好的张力；关键在于是否改变决策，而不是文字表面相似或相反。

### 3. 允许专门化，但要提供进入它的路

依赖格挡的攻击、依赖弃牌的收益牌、需要整理牌组的终结牌，可以在条件不满足时很弱。专门化让构筑有目标。

但低稀有度入口整体需要足够可用。若玩家连续看到的都是“以后有配套才有用”，卡池会缺少可靠过渡。

### 4. 条件必须换来有意义的选择

“本回合第三张牌”“资源至少达到某值”可以组织节奏，也可以只是增加记忆负担。每加入一个条件，都要说明它为什么改变出牌顺序、拿牌偏好或风险承担。

能直接用已有资源的花费、延迟、消耗或位置约束表达时，通常不需要额外叠加多个判定门槛。

## 七、设计真正的突破牌

突破牌让玩家重新评价此前拿到的牌。它应当能用一句话说明改变了什么边界。

| 突破方向 | 产生的变化 | 必须关注的代价 |
| --- | --- | --- |
| 资源不再流失 | 当回合资源变成可积累资产 | 是否可以无风险无限等待 |
| 来源本身产生收益 | 做机制同时获得抽牌、防御或成长 | 同一行为是否同时补回全部成本 |
| 容量或倍率扩大 | 之前溢出的投入可以继续积累 | 是否挤压了其他获胜方式 |
| 改变支付方式 | 使用其他资产支付，或降低原本费用 | 新成本是否真实存在 |
| 额外打出与复制 | 高价值目标获得更大回报 | 收益是否和资源生成互相递增 |
| 持续生成 | 原本不稳定的来源变为稳定供应 | 启动后是否仍需选择与管理 |
| 改变资源用途 | 防御可输出、牺牲可成长等 | 转换是否抹除了原有弱点和取舍 |

提高伤害的强牌可以是好终结牌，不必硬称为突破牌。角色同时需要稳定工具、构筑收益与令人期待的上限。

## 八、升级应该加强什么

升级首先应该强化这张牌原有的职责，保持辨识度。

| 方式 | 适合解决的问题 | 复核重点 |
| --- | --- | --- |
| 提高数值 | 可靠性和效率不足 | 是否压倒同职责的其他牌 |
| 降低费用或代价 | 难以安排进回合 | 是否让一个循环失去最后的成本 |
| 扩大选择或目标 | 操作空间狭窄 | 是否增加过多选择负担 |
| 改善获取时机 | 核心牌启动不稳定 | 固定首回合出现是否反而挤占攻防 |
| 增加重复使用 | 一次性效果需要成为持续工具 | 重复后是否改变整套资源收支 |
| 减少副作用 | 原有风险过大 | 特色取舍是否被完全取消 |

不要让大量牌“不升级就不能正常工作”。营火选择应当有竞争：提高即时战力、稳定核心、改善循环、保留休息机会，都应有合理场景。

## 九、数值与平衡：评价完整成本

### 1. 能量只是成本的一部分

还要计入抽牌机会、占用手牌、准备动作、等待回合、生命损失、一次性消耗、长期资产、目标限制，以及组合需要的其他牌。

一张免费衍生牌背后可能有生成费用；一张高伤害牌可能依赖数回合准备；一张“代价很大”的牌也可能在常见配合下不再支付代价。按实际使用路径评价。

### 2. 用原版样本建立参照，不建立万能汇率

选取相近费用、稀有度、用途和限制的原版牌进行比较，再说明新角色额外获得什么、额外付出什么。

不要给“抽一张”“一点力量”“一张衍生牌”制定跨角色通用的固定价值。多段攻击改变力量收益，廉价牌改变抽牌收益，回收与保留改变一次性资源的意义。

### 3. 每张关键牌检查三种状态

| 状态 | 需要观察 |
| --- | --- |
| 没有配套 | 能否过渡；不能过渡是否符合其职责 |
| 常见配合 | 两三张容易获得的牌组合后，收益是否合理、操作是否顺畅 |
| 成熟构筑 | 能否形成令人满意的上限；是否仍有成本、风险和终结方式 |

稀有度降低获得频率，却不会自动平衡拿到后的收益。复杂操作也不能被当作过强效果的充分代价。

### 4. 检查循环的完整收支

对可重复操作，记录一轮结束后：能量是否减少、关键牌能否回来、资源是否耗尽、生命或资产是否损失、抽牌和位置是否恢复，以及是否持续获得伤害或防御。

如果一轮后能回到相同起点，并持续产生收益，就需要认真判断它是否符合角色预期。先弄清循环成立条件，再选择调整来源、回收、收益或限制。

不必给所有触发统一添加“每回合一次”。高门槛、需要投入的强组合可以是乐趣；随手两张常见牌就消除所有资源限制，则可能吞掉整个角色的其他路线。

### 5. 保护角色弱点

弱点让选牌和路线选择有意义。允许玩家通过投入改善弱点，但如果同一个廉价引擎同时解决伤害、防御、能量、抽牌和成长，其他卡位很容易失去价值。

## 十、遗物、药水与局外收益

### 遗物扩展偏好

起始遗物保证身份和最小体验；其他专属遗物可以奖励不同使用方式、降低部分启动压力或提供新取舍。

不要把基本可玩性锁在随机获得的专属遗物后。也不要让每件遗物都重复增加主资源，最终只剩数值叠加。

### 药水提供临时窗口

专属药水适合帮助紧急启动、完成一次爆发、获得临时防御或调整关键资源。它应当让玩家决定什么时候使用，而非成为每场战斗都需要的机制补丁。

### 局外收益按整局评价

金币、回复、永久成长、删牌、奖励牌和遗物，会改变后续路线与资源压力。当前战斗中的温和效果，也可能通过重复获取变成很强的长期优势。

检查玩家是否会为了积累收益拖延战斗，以及这种行为是否有趣。避免让最佳玩法变成反复执行低风险、低决策的劳动。

## 十一、多人设计要创造协作决定

多人牌可以分享资源、传递对象、协调时机、承担风险或改变队友的选择。单纯给队友数值并非无效，但角色专属玩法通常能提供更有辨识度的协作。

设计时回答：谁付成本、谁作选择、谁获得收益、收益何时到来、队友需要知道什么。

同时考虑同角色组合与不同角色组合。只能和同角色合作的牌会缩小使用范围；直接替队友决定弃牌、花费资源或改变构筑，则可能削弱对方的参与感。

多人专属内容与单人卡池分别检查。还要观察队友等待时间，避免一人的强组合让其余玩家长时间没有行动机会。

## 十二、卡面文字与体验表达

卡面优先写清动作、对象、数量和必要时点。用词保持一致，让玩家能够依据卡面预测结果。

公共规则放进关键词说明，特殊条件只在确实必要时出现。不要通过隐藏关键代价来缩短文字，也不要用大段解释弥补本身过于曲折的机制。

数值变化、资源去向、延迟收益和失败条件应当容易被看见。玩家作出一次选择后，应该知道发生了什么，以及为什么发生。

命名可以来自动作、物品、场景或人物关系。不同层级允许不同语气：普通牌朴素易懂，核心牌容易记住，终结牌具有表现力；不必让所有牌都像终极绝招。

## 十三、推荐的设计推进顺序

| 阶段 | 产出 | 进入下一阶段的条件 |
| --- | --- | --- |
| 1. 角色定位 | 核心体验、矛盾、优势、弱点 | 能清楚说明与已有职业的决策差异 |
| 2. 最小机制 | 来源、用途、限制与两种使用方向 | 不依靠大量特殊牌，也能说明选择为什么成立 |
| 3. 起始体验 | 起始卡组与遗物的完整关系 | 前几场战斗可玩，玩家能亲自完成机制循环 |
| 4. 代表牌 | 少量入口、来源、收益、连接与终结样本 | 普通操作与成熟玩法都能成立 |
| 5. 卡池扩展 | 稀有度、功能与体系需求表 | 扩展在补充情境和选择，没有大量近似重复牌 |
| 6. 配套内容 | 遗物、药水、特殊获取与多人内容 | 丰富玩法，同时保留基本可玩性 |
| 7. 对局迭代 | 问题记录与修订理由 | 能从具体失败或过强场景解释每次改动 |

建议先用约十到十五张代表牌作为讨论样本，覆盖起始体验、基础战斗、机制收益和一个成熟组合。这是验证设计方向的规模建议，不是完整角色的交付牌数。

不要在机制还没有成立时直接写完整卡池。也不要只设计最炫酷的稀有牌，再用大量普通牌勉强替它们提供燃料。

## 十四、用实际对局修正判断

既要看顺利成型的对局，也要看迟迟没有核心、奖励偏离计划、早期高压、长战斗、多敌人和资源不足的情况。

| 观察项 | 有价值的问题 |
| --- | --- |
| 拿牌与跳过 | 哪些牌总被拿、总被跳？是强度、理解成本还是配套密度造成的？ |
| 启动 | 玩家通常何时开始发挥核心玩法？启动前是否长期处于无法应对的状态？ |
| 生存 | 损血来自合理取舍，还是没有可用防御？ |
| 终结 | 牌组如何赢？是否所有路线最终都依赖同一张牌？ |
| 升级 | 是否有强制升级项，导致其他升级没有竞争力？ |
| 多样性 | 不同获胜牌组是否真的有不同拿牌和出牌决策？ |
| 操作负担 | 是否需要大量重复选择，收益却很小？ |
| 主题理解 | 玩家能否用自己的话描述角色在做什么？ |

记录难度、路线、关键奖励、玩家熟练度与样本数量。胜率、选取率和跳过率都需要情境解释：高选取可能来自过强，也可能来自角色缺少其他解决办法。

每轮修订尽量围绕一个明确假设，例如“来源不够稳定”“基础防御不足”“循环回收过于便宜”。改完后观察对应问题是否改善，避免同时修改大量变量后无法判断原因。

## 十五、可直接使用的设计记录表

### 角色设计简表

| 字段 | 填写内容 |
| --- | --- |
| 一句话体验 | 玩家主要做什么选择 |
| 主题与操作的关系 | 为什么这些动作符合这个角色 |
| 核心资源或事件 | 来源、用途、限制、流失方式 |
| 主要路线 | 各自的抓牌理由、输出、生存与运转方式 |
| 路线之间的联系 | 共享什么，又竞争什么 |
| 优势与弱点 | 哪些压力应当保留 |
| 起始体验 | 玩家如何首次完成机制循环 |
| 卡池范围 | 常规、基础、特殊来源、衍生与多人分别规划 |
| 成熟体验 | 最希望玩家达成的组合和终结方式 |
| 已知风险 | 过度依赖、循环、复杂度与操作负担 |

### 单卡设计简表

| 字段 | 填写内容 |
| --- | --- |
| 名称、稀有度、类型与费用 | 基本身份 |
| 基础效果与升级效果 | 可以直接理解的卡面表达 |
| 卡位职责 | 入口、来源、收益、连接、突破、终结或通用工具 |
| 拿牌理由 | 什么牌组、什么阶段会想要它 |
| 新增选择 | 它怎样改变出牌顺序或资源分配 |
| 实际成本 | 能量之外还付出什么 |
| 最近似的现有牌 | 两者各自的使用情境 |
| 组合表现 | 无配套、常见配合、成熟构筑分别如何 |
| 升级理由 | 为什么值得一次升级机会 |
| 待验证问题 | 哪种对局结果会说明需要重做 |

### 完整卡池复核

- 角色身份能否用玩家行为说明，而不是靠术语数量说明？
- 起始体验是否能教会核心机制？
- 普通层是否提供可靠战斗与可见入口？
- 来源、收益和终结是否互相支持？
- 混合构筑和没拿到理想核心的对局是否仍可玩？
- 稀有牌是否有值得期待的机会，而非普遍替代普通牌？
- 每张相似牌是否都有不同的拿牌情境？
- 升级、复制、回收和重复触发是否改变了预期成本？
- 遗物、药水与多人内容是否扩展了选择？
- 是否保留角色弱点，并控制文字与操作负担？

本指南参考原版五职业的卡池研究、既有角色 Mod 的设计案例，以及《职业卡池设计要求》《体系分析流程》《卡牌分析流程》《体系驱动卡池设计流程》中的分析方法。所列流程和模板用于帮助判断，不替代具体角色的玩法目标与对局验证。
