01 / 从角色到操作

保留执念，也保留狼狈。

值得转译的不是“她会一招大火球”，而是：一个有天赋的人，把成长投入同一招，并接受由此产生的不便。核心玩法应让玩家亲手作出类似选择。[1]

爆裂专精 → 成长的出口集中

威力、速度、施放窗口、善后可以多样；不必靠学习冰火雷凑出多流派。

施放后脱力 → 强弱节奏有反差

代价应改变接下来如何操作；完全不能行动只会缩短参与时间，不自动等于还原。

高天赋与坚持 → 可规划、可精进

起始体验就能接触爆裂，不能等抽中一张稀有牌才成为惠惠。

咏唱与登场 → 准备也有表演感

可以转成顺序、时间或投入，但不能把长动画当平衡成本。逐层咏唱计数是游戏改编。

协作与照应 → 创造窗口、预留退路

队友题材适合支援卡；单人仍能自洽，不让别人每场替惠惠承担所有防御。

物资突破 → 少量珍贵的例外

后期外部补给可以启发额外施放；昂贵、有限比每回合自动补满更有辨识度。

这次的判断标准

去掉卡名后，玩家是否仍然在决定“什么时候投入、什么时候兑现、没结束战斗怎么办”？若答案只是多打牌、多叠伤害，人物主题还没有进入操作。[3]

02 / 六种不同的决策引擎

先比较核心，再决定卡池。

以下六种是可替换的主结构，不建议同时安装。A、B 关注施放次数与节奏；C、D 改变准备方式；E 把爆裂看作透支；F 把牌组本身当作燃料。点击查看完整提案。

03 / 同一把尺子

最有辨识度，不一定最耐玩。

定性设计判断，尚无试玩数据。“风险”描述结构问题，不是评分。
方向主要选择长战与多阶段认知负担关键失效模式本轮去向
A · 单发终结何时越过斩杀线最脆弱；需备用胜法低一发秒杀或一发后无事可做主题对照组
B · 蓄势／脱力现在兑现还是继续投资基础规则允许再启动中最快循环成为唯一答案优先验证
C · 咏唱编排留哪些牌、怎样组织顺序可重复组织，但怕卡手高每场背同一套出牌口诀第二主方案
D · 战术窗口追求威力还是把握机会依赖不同敌人是否给窗口中高敌人决定了玩家能否玩拆为辅助层
E · 透支恢复提前获得多少未来战力能打，但连续透支易崩盘中减免代价后变成免费连发独立挑战原型
F · 燃尽牌组牺牲哪些未来工具会耗尽资源或缩出无限中高越消耗越强，代价反成奖励小规模插件

如果你最看重“就是惠惠”

优先比较 A 与 B。A 的一发限制最鲜明；B 把“脱力后怎么办”也纳入操作，对完整爬塔更有承载力。

如果你最看重出牌技巧

让 C 与 B 正面对照。C 的手牌组织更丰富，但必须证明它不只是每场寻找同一套组合技。

这里没有给六种方案打加权总分：角色还原、复杂度与容错的权重属于设计偏好，不能伪装成客观测量。

04 / 优先验证的假设

一个爆裂核心，三个相互竞争的投入方向。

建议先做 B：准备资源 + 施放事件 + 短暂脱力。把“极限一发、快速施放、周到善后”作为同一机制的构筑路线；暂时不宣称它们已经是三个独立大体系。[2][4]

01

准备

用攻防与整理手牌建立咏唱。能提前打，但继续投入有更高回报。

02

爆裂

支付能量，消耗全部咏唱，对全体敌人兑现伤害。决定是否留资源善后。

03

脱力

经历一个受限回合，仍可防守与整理。随后从低储备重新准备下一发。

核心矛盾：提高这一发的威力、提前降低场面压力、为下一回合留退路，争用同一回合的能量和抽牌。

一套可以实际推演的最小规则 R0

以下全部为测试规则，不是最终数值或原作规定。暂不依赖游戏引擎具体 API。

唯一计数器
咏唱 C，战斗开始为 0，上限 8，跨回合保留。爆裂消耗全部 C；没有额外魔力条或热量条。
基础来源
准备牌提供 C；非脱力状态下，本回合未施放爆裂且结束时仍有能量，则获得 1 C（固定一次，剩余能量照常失去）。两种来源都占用可用于即时攻防的资源。
可靠入口
战斗开始获得一张专属“爆裂魔法”：2 费、保留，不占正常抽牌；施放后暂时离开牌堆。脱力结束后的回合开始重新获得。候选实现为起始遗物供给，需验证手牌上限交互。
施放
C 为 0 也可打出。对每个敌人造成 12 + 6C 点基础伤害；随后 C 清零并进入脱力。伤害受正常攻防修正；这些数值只用于本页推演。
脱力窗口
施放后立刻禁止再次爆裂；下一玩家回合能量比正常少 1（不低于 0），不能获得 C。该回合结束时解除；其余攻击、防御、抽牌照常。施放当回合余下时间也不能获得 C。
再启动
若第 2 回合施放，第 3 回合受限，第 4 回合拿回爆裂并恢复准备。再施放不依赖稀有牌；重新蓄势仍花费能量与时间。
边界
同回合复制／重放也受“本回合已爆裂”检查限制，不能靠复制绕过脱力。突破牌必须明确改写哪条限制；不默认允许药水或净化移除此职业阶段。
为什么给“未用完能量”一个来源？

让准备不完全取决于抽到指定卡，也让“打出最后一张防御，还是保留能量增加下发威力”成为选择。它也可能鼓励无聊空过：若实测总是剩 1 能量最好，就删掉或重做这一来源，而不是继续堆补丁。

极限一发

更愿意拿高投入咏唱、跨回合防护和一次性增幅。收益来自高库存的一次清空。

放弃的是速度；最怕准备期间持续受压。必须允许低准备提前施放止损。

高速施放

更愿意拿低费入口、滤牌和早期窗口工具。目标是先清掉危险敌人，再处理残局。

放弃的是单发效率；脱力与重新蓄势阻止无成本连发。不能把所有低费抽牌同时写成咏唱来源。

周到善后

更愿意拿提前安排下一回合防御、保留关键牌和脱力时仍可用的工具。

放弃的是当前伤害；善后能覆盖损失，但不应完全取消低谷。未准备保护时仍有真实风险。

值得争论：自动返还爆裂会不会削弱抽牌构筑？

会。可靠供给把抽牌难题从“找终结牌”移到了“找准备与保护工具”，也削弱了传统检索价值。这是刻意选择：第一轮先验证施放时机，不把失败混同于抽不到身份牌。后续可与“保留的实体牌，施放后入弃牌堆并按阶段锁定”对照；如果检索版只是更容易卡手，则保留自动供给。

值得争论：脱力能否完全靠牌抵消？

可缓解，但不应普遍免费消失。先保留一个不可跳过的受限回合，观察防御规划是否有趣。之后只测试“每场一次缩短窗口”的稀有突破，与持续循环分开；若玩家永远选择抵消脱力，这说明原本的低谷没有足够可操作性。

公式：D = 12 + 6C；后发 C′ = min(8, C + ΔC)。有效总伤害 = 敌人数 × min(H, D)。溢出伤害不会自动变成收益。两条路线的脱力回合、抽牌差异、后续敌人行动与长期击杀时间未模拟。

离线交互样例：C=3、双敌各28生命时，当前每敌30伤害已经清场；等到 C=5 只增加溢出伤害，还多承担等待损血。若每敌45生命，则当前30、等后42，仍未斩杀；需要继续规划脱力。

真正的深度不只来自斩杀计算

若所有选择最终都化简为“够伤害就打”，还需要让施放后保护、下一手质量或危险敌人优先级改变答案。数值阈值只能搭骨架。

长战是最重要的反证

爆裂打不死高血量目标时，B 应仍有完整计划。若必须依赖稀有补魔才能继续，所谓可循环只是纸面承诺。

准备端：提供威力的不同成本

即时防护附带少量咏唱、纯投入的快速咏唱、消耗手牌换咏唱。三者不同在付出了什么，而不只是名字不同。

运转端：支持决策，避免自给自足

三张非稀有抽牌示例分别承担筛选、稳定防守、跨回合整理。暂不让它们又抽牌、又产咏唱、又返还能量。[7]

连接端：同一行为有两种意义

“孤注一掷”把消耗牌组的代价转为爆裂燃料，可小范围借用 F。“预留退路”让施放时机与未来防御直接相连，无需发明新的支援计数器。

突破端：改变边界，不只增加数字

“精确爆破”改变目标范围与适用战斗。另可测试“每场一次带着低准备再放”的物资牌，但不能同时解除脱力、免能量、补满咏唱。

哪些素材先留在辅助层？

魔力矿石：后期、有限机会的突破，具体数量与还原边界待查。队友：创造窗口、照应善后，不独立模拟四人队。逗之助：陪伴、整理或工具，暂不设召唤物主攻系统。每日练习：升级分支或局间成长，不奖励拖住已获胜的战斗无限刷威力。眼罩：演出与自我宣言，不默认真实邪眼能力。

07 / 让方案有机会被推翻

先做 B 与 C 的对照，不先造完整职业。

推荐顺序：先用 B 建立可靠的起始体验，再用 C 替换准备结构。A 用来检验是否失去了“一发的重量”；E、F 保留为独立实验，不混入第一轮。

下列为拟议验收标准，尚未执行；测试场景是抽象局面，不冒充当前版本具体敌人数据。
要测什么固定场景观察指标失败后改哪里
首回合可玩机制牌沉底、首回合高压记录可行防守动作与首次施放时点；无稀有也能启动先补起始攻防与入口，不提高终结上限
时机有选择小怪群、斩杀边缘、持续加压至少找到早打更好、晚打更好各一个局面；说明理由调整等待回报或场面缓解，删掉无条件最优来源
脱力有操作第一发没击杀；脱力手牌最差排列至少存在防御、整理中的可行行动；不能连续整回合无事可做降低行动剥夺，补普通工具；不先发免费再启动
长战不锁死高血量与二阶段重置无稀有、无药水完成第二次准备与施放，记录损血检查恢复窗口与基础伤害，不用稀有补魔补洞
构筑真分化相同战斗，分别偏重威力／速度／善后拿牌和出牌优先级发生改变；不是同一牌组换两张牌加强相互竞争的成本，而非三种独立增伤标签
不出现零成本循环复制、减费、额外能量、消耗回收同回合不能无限爆裂；返牌和触发顺序可解释先修结算边界与次数限制，再调数字
多人不绑架队伍队友先清小怪、未能提供保护不必让队友停手；仍可对剩余目标做贡献减少严格斩杀奖励与被迫等待，保留独立防御

第一轮怎样记录，才不是凭感觉选方案？

  1. 为 B、C 各准备相同攻防底座、6 组抽象敌人脚本与3组固定抽牌顺序，每方案至少18次纸面对局。先比较结构，不声称样本代表胜率。
  2. 记录：每次爆裂回合、施放时储备、总损血、脱力中有效行动数、死牌次数、第二发是否可达，以及“是否存在值得考虑的另一种打法”。
  3. 每轮只改一个变量：准备收益、施放费用或脱力限制。只要某路线在全部脚本都支配其他路线，就先查资源交换是否没有代价。
  4. 纸面通过后再在目标游戏版本验证牌堆、复制、阶段转换与多人结算。现仓库是研究资料包，没有可据此宣称兼容或平衡完成的游戏实现。
当前设计判断：B 值得先做，但还没有“通过”。

它有清楚的资源来源、兑现出口与重复施放的代价；最大的疑点是脱力是否只剩固定空档，以及最快循环是否支配极限蓄势。C 则需要证明顺序选择能随手牌变化。答案只能来自原型记录。

保留给下一轮的四个决定

① 爆裂在哪里
先用自动供给保证身份；再对照保留实体牌，看检索是否增加乐趣。
② 低谷有多重
先用一回合少 1 能量、暂停咏唱；不要同时降低抽牌、清空格挡并禁止攻击。
③ 长战如何成长
先允许完整再启动；再评估是否需要战斗内威力成长。避免每次施放自动永久增伤。
④ 高速能多快
先保留同回合禁止再发；每场一次的例外单独测，避免一张稀有牌取消角色全部弱点。
08 / 依据与解释范围

哪些来自资料，哪些是本页的推导。

本页基于仓库已保存的研究。未进行新的原作逐卷核对或游戏版本核验。为方便单文件阅读，关键依据与取舍已写在正文；以下文件名用于追溯，不要求打开原文件才能读懂方案。

[1] 惠惠角色特点与设计素材.md

采用：爆裂专精、经典施放后脱力、天赋与执念、日常练习、协作创造窗口。该研究区分官方确认与二手整理。本页不升级其证据等级。

研究列出的原始入口：动画官方角色页 · 第4话日常练习 · 第10话协同作战。这些链接用于继续查证，本页未重新访问。

[2] 惠惠核心机制初探.md

继承“准备—爆裂—脱力”和极限一发／高速施放／周到善后的初步方向。本页新增：六方案展开、具体规则 R0、交互阈值演示、卡位示例与反证标准。推荐方向与旧文一致，但不是用户已批准的定稿。

[3] 新角色Mod通用设计指南.md

采用：先确定反复决策；明确来源、用途、限制与变化；起始可玩；普通工具兜底；主机制复杂时压缩副机制。

[4] 体系分析流程.md

采用：共同扳机与收益、输出／防御／运转三个端口；不把高伤害、抽牌或保护队友等功能标签当作独立体系。

[5] 职业卡池设计要求_按五职业规律.md

采用：入口、来源、收益、连接、突破的卡位分工；允许一个主机制占主导。不把其中版本相关的卡牌数量、费用分布当作本项目硬配额。

[6] 五职业卡牌分析总结.md · 卡牌分析流程.md

采用：奖励层级承担不同职责；区分基础牌种类、张数与衍生牌；分析每张牌的实际拿牌原因。未生成全卡池，不声称完成稀有度与端口统计审计。

[7] 体系驱动卡池设计流程.md

采用：多来源、多路线、复杂度预算、至少三张非稀有抽牌的设计目标、突破牌应改变边界。它是参考方法，本轮不是完整卡池生产流程；没有虚构多角色审稿或“已通过”记录。

[8] README.md · 网络来源与访问记录.md

项目定位为角色研究与核心玩法探索。按 README 的范围说明：萌娘百科正文此前未成功读取，不能当作已验证证据；局间与“一天”的映射是改编决定。
